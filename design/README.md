# AvaGithubDesktop 产品交互原型

`index.html` 是可单独复制、离线使用的产品原型。源码位于 `scripts/prototype/`，菜单结构从实际 `MainWindow.axaml` 生成，中英文案复用宿主 JSON；原型专属说明位于该目录的语言 JSON。原型不是应用构建输入。默认显示桌面留白、外边框、标题栏和窗口按钮；`?capture=window` 用于去掉展示留白并按原生尺寸量测。

当前以真实产品功能重整，替代早期简化的侧栏壳：

| 产品区域 | 原型操作 |
| --- | --- |
| 六个主菜单 | 文件、编辑、视图、仓库、分支、帮助；保留实际菜单层次、快捷键和暂停操作的禁用状态 |
| 仓库、分支、远端栏 | 切换样例仓库与分支、新建或克隆表单、远端配置预览 |
| Changes | 筛选、勾选、逐文件 Diff、提交摘要与说明、修订提交、暂存与恢复 |
| History | 提交列表、提交摘要、300 px 文件列与对应 Diff、复制 SHA 和提交操作入口 |
| 工作区 | 左右及上下分隔器、日志显隐、快捷键跳转 |
| 外观与语言 | Ursa 风格三态按钮、八套平铺色圈、语言图标展开中英菜单、同窗切换与偏好恢复；标题栏不重复放置下拉框 |
| 关于 | 650 × 650 窗口、八项元数据、检查／下载／校验／安装交接／失败／取消／无资产状态 |

Git 数据和更新结果均为受控样例；离线原型不访问网络、不操作本地仓库、不启动外部编辑器或安装器。系统入口展示目标预览，后台 Git 操作写入样例日志。它用于验证界面和状态关系，真实服务由桌面程序验收。

```powershell
node scripts/prototype/build-resources.cjs
pwsh scripts/build_standalone_prototype.ps1
npm ci --prefix design/tests
npm test --prefix design/tests
```

`build-resources.cjs --check` 校验菜单和翻译同步，`build_standalone_prototype.ps1 -Check` 校验交付 HTML。浏览器门禁将唯一 HTML 复制到空目录，阻断外部资源，检查双语八色、系统变化、两种窗口宽度、提交／暂存／分支操作、分隔器、关于及更新状态。

## 同尺寸对照与边界

基线为 Windows x64 原生 Skia 输出的 1120／1440 × 900 双语截图。标题栏 44 px，仓库条 50 px，左列 360 px，Diff 边界 `(386,123)`，日志 180 px，状态栏约 28 px。七类区域跨四个视图共 28 个矩形的最小交并比为 96.43%，达到这些区域 95% 的布局验收线；这不是整页像素相似率。原型与原生的 Changes 和 History 主结构已对齐。

仍有可见差异：浏览器输入控件、字体抗锯齿、系统窗口按钮、Git 图标笔触、动态日志及提交时间来自不同渲染环境；关于页编译时间统一为 `2026-10-15 00:00:00`。图像／二进制 Diff、复杂冲突处理与完整系统文件选择器沿用应用能力，原型未模拟其底层算法。不能用 32 个组合的通过数量推算视觉还原率。
